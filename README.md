# Kingware — external GUI на C++

Отдельное нативное окно для Windows 10/11: **C++17, Dear ImGui, Win32 и DirectX 11**. Интерфейс оформлен в тёмной теме с оранжевым акцентом; окно можно перемещать за верхнюю панель и менять его размер. Это не сайт и не DLL.

## Что уже сделано

- Вкладки **Aimbot**, **Visuals**, **Resolver**, **Miscellaneous** и **Debug**.
- Настройки цели: FOV, точка, visible only, команда, multipoint, smooth и humanization. Справа — интерактивная **симуляция**, где они применяются к тестовой цели.
- Визуальные настройки: боксы (уголки / полный), HP, броня, имя, оружие, дистанция, скелет, цвета и варианты chams. Всё показано на нарисованной средствами ImGui тестовой модели. Кнопка «Виден / Скрыт» меняет состояние модели.
- Локальный профиль: автосохранение после изменения, кнопки сохранения и подтверждаемого сброса. Файл находится в `%APPDATA%\Kingware\settings.ini`.
- Debug показывает отсутствие адаптера драйвера и подключения к игре, а также справочник из 98 переданных offsets с поиском и копированием. Длинные значения в таблице можно увидеть полностью при наведении.
- В `src/aim.cpp` есть отдельная тестируемая математика выбора ближайшей подходящей экранной точки и плавного движения. Она работает **только с переданными ей данными** и не управляет мышью или игрой. FOV здесь измеряется в условных экранных пикселях; видимость берётся из входных данных для хитбокса, а не вычисляется по препятствиям. `humanization` — небольшое колебание в симуляции, а не средство обхода обнаружения.
- В `src/memory_reader.hpp` подготовлены интерфейс адаптера и безопасная заглушка: она всегда возвращает ошибку чтения и не открывает устройства. Протокол реального драйвера пока не известен.

## Важно: что ещё не подключено

Это **GUI и демо**, не готовый рабочий чит для Rust. Здесь нет драйвера, проверки его состояния, чтения памяти, поиска процесса, игровой камеры/списка объектов, игрового оверлея, вывода chams, управления прицелом или реализации resolver для игры. Переключатели не активируют эти функции в Rust. Статус драйвера «нет адаптера» означает, что проверка не реализована, а не результат сканирования системы.

Offsets из сообщения сохранены в `src/offsets.hpp` как **непроверенный справочник**. Версия игры, базовые модули и семантика цепочек не известны: например, `+ 0x12F + 0xE0` само по себе не объясняет, где разыменовываются указатели. Значения не используются для чтения памяти и могут быть неактуальны. Использование подобных инструментов может нарушать правила игры или сервера.

Для следующего шага можно прислать уже имеющиеся исходники: интерфейс и протокол драйвера (имя устройства, IOCTL и структуры запросов), код получения сущностей/матрицы камеры, а также точную версию Rust. Не нужны пароли, токены или приватные ключи.

## Готовая демо-сборка

Скачайте [архив для Windows x64](https://github.com/bulbau23232323/dllkingware/releases/download/v0.1.1-demo/Kingware-GUI-demo-win64.zip) на странице [релиза v0.1.1-demo](https://github.com/bulbau23232323/dllkingware/releases/tag/v0.1.1-demo), распакуйте его и запустите `Kingware-GUI-demo.exe`. Это только GUI и симуляция, без подключения к Rust и драйверу. Ручной запуск игры и GUI на Windows не проверялся.

## Сборка в Windows

Понадобятся Visual Studio 2022 с компонентом **«Разработка классических приложений на C++»**, Windows SDK и CMake 3.24+. При первом конфигурировании обычного исходного кода CMake скачает зафиксированную версию Dear ImGui из GitHub и проверит SHA-256 архива. Отдельный архив исходников в релизе включает ImGui в `third_party/imgui` и может собираться без сети.

В PowerShell из корня проекта:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
.\build\Release\Kingware.exe
```

Проверки:

```powershell
ctest --test-dir build -C Release --output-on-failure
```

Для сборки без сети можно заранее скачать исходники Dear ImGui **v1.91.9b**, commit `f5befd2d29e66809cd1110a152e375a7f1981f06`, и передать путь к ним в CMake:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DFETCHCONTENT_SOURCE_DIR_IMGUI="C:/path/to/imgui"
```

На Linux можно собрать и запустить тесты конфигурации, математики и ImGui без окна. Само приложение использует Win32/DirectX 11 и собирается только под Windows.

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Dear ImGui распространяется по [лицензии MIT](https://github.com/ocornut/imgui/blob/f5befd2d29e66809cd1110a152e375a7f1981f06/LICENSE.txt).
