## Скачать

- **Kingware-GUI-demo-win64.zip** — программа для Windows 10/11 x64. Распакуйте архив и запустите `Kingware-GUI-demo.exe`.
- **Kingware-GUI-demo-source.zip** — исходники C++, тесты и Dear ImGui; архив можно собрать без скачивания зависимостей.
- **SHA256SUMS.txt** — контрольные суммы архивов.

## Важно

Это **предварительная демо-версия интерфейса**, а не готовый чит для Rust. Aimbot, ESP и chams работают только в симуляции; драйвер, чтение памяти и подключение к игре не реализованы. Offsets из сообщения не проверены.

Приложение и тесты собираются в Windows CI. Ручной запуск интерфейса на Windows не проводился. Настройки сохраняются в `%APPDATA%\Kingware\settings.ini`.
