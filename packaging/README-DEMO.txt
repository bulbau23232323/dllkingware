KINGWARE GUI DEMO v0.1.0

Windows 10/11 x64; DirectX 11 is required.

1. Extract the entire archive to a folder.
2. Run Kingware-GUI-demo.exe.
3. Use the tabs to configure and preview the interface.

IMPORTANT: This is a GUI and simulation only. There is no driver, Rust
connection, real ESP/chams overlay, or working in-game aimbot in this build.
The provided offsets have not been verified. The app has not been manually
run on a Windows desktop, even though it is built and tested on Windows CI.

Settings are stored in %APPDATA%\Kingware\settings.ini.
Source code and build instructions are included in the separate source ZIP.
